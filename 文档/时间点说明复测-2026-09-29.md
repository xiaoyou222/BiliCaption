# 时间点说明复测

## 已实现

- 片段卡片显示时间点和选择原因，原字幕仅用于内部核对。
- 模型返回 `{line, reason}`；程序定位字幕并保存来源。没有合适引用可以留空，不凑两条，也不要求正反各一条。
- 原因须说明当前维度的具体优点或问题，不能仅摘抄字幕或使用通用标签。
- 普通教程只按其正常路径和必要条件评价充分性，不因缺少失败、排错、返工而扣分。简单操作不要求展开所有点击；不把字幕未念出的画面内容判定为缺失。
- 规则版本 7、评分结构版本 4。旧评分缺少引用原因，重新评估一次后继续复用；大纲缓存独立。

## 实际模型复测

样本：[Claude Cowork 手把手教学](https://www.bilibili.com/video/BV1dLSoBGEPp/)，使用已有的 367 行字幕和视频标题，通过扩展现有模型配置调用。测试没有改写用户的评分缓存，也没有将画面观察加入模型输入。

第一次返回把引用行号写成了 1046，超过字幕范围，被校验拦截。原输入的行号与开始秒数都是数字，容易混淆；推荐专用输入已改为“第 N 行 / 时间 分:秒 / 文本”，长视频分段保留全片行号，不影响大纲格式。

修改输入格式后，第二次返回通过结构、范围和原文核验：

| 维度 | 分数 |
| --- | ---: |
| 充分性 | 8.0 |
| 逻辑性 | 9.0 |
| 干货度 | 8.0 |
| 标题党 | 0.0 |
| 推荐指数 | 8.8，值得看 |

实际返回两条引用，其余维度留空：

| 时间 | 模型选择原因 | 人工核对 |
| --- | --- | --- |
| 04:06 | 核对名册任务结果：字幕说明 Excel 已拆栏并附人数统计 | 第 78 行说明拆栏，第 79 行说明人数统计，支持充分性理由中的任务结果 |
| 09:13 | 核对必要条件：睡眠或程序未开会导致排程无法执行 | 第 178–179 行说明电脑与程序须保持运行，支持逻辑性理由中的前提条件 |

这两处定位和内容一致，但“核对结果 / 核对条件”仍偏中性。因此随后补强了措辞要求：开头直接说明“操作交代清楚”“关键条件已说明”或“缺少关键步骤”等具体表现；说明失败的触发条件本身可以是讲解优点。此项补强做了提示词契约检查，未再调用模型，最终措辞仍需在后续试看中观察。

## 验证范围

- 自动化覆盖片段原因解析、内部引文校验、无效引用、空引用、缓存升级、显示原因和点击跳转。
- 全量测试 407 项通过，扩展打包成功；设计稿脚本语法与规则文档同步检查通过。
- 前端视觉效果按约定由用户验收。此次实际调用只能证明该样本成功，不能保证模型每次选择的片段在语义上都恰当。
