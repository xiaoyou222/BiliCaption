# 标题党：没有具体误导时应为 0 分

## 原因

[分享几个 Codex 实用小技巧](https://www.bilibili.com/video/BV1eWtE62E73/)的原标题由 B 站接口核对，扩展已有完整字幕 89 行。旧评分的标题党为 2 分，理由只说明正文介绍了多项功能、整体兑现标题，没有指出任何具体夸张或未兑现的承诺。

旧提示词把“0–2”全部归为标题忠实，允许模型在没有发现问题时仍给 1–2 分。这不符合“标题党分数代表误导程度”的含义。

## 当前规则

- 无具体误导且承诺已兑现，必须为 0 分，不因保守或避免极端值留分。
- 大于 0 分时，必须指出标题中的具体承诺或措辞、正文实际内容，以及两者的偏差。
- 1–2 分限于有依据的轻微局部夸张或偏差，不能用于表达不确定性。
- 标题只承诺几个技巧，就按对应技巧是否提供来判断，不额外要求完整课程、系统教学或完整项目。
- 理由只有标题与内容相符、没有具体偏差时，分数应为 0。充分性仍负责讲解和操作是否到位。

## 实际模型复测

使用扩展当前配置的模型与公共调用层，输入标题及全部字幕，未添加热评与互动数据。

| 输入 | 标题党分数 | 结果 |
| --- | --- | --- |
| 原标题，第 1 次 | 0 | 识别为多项 Codex 功能与用法，未发现具体标题偏差 |
| 原标题，第 2 次 | 0 | 同样判定为兑现标题 |
| 同一字幕，人工替换为“从零做出并部署一个完整网站：Codex 全流程实战” | 8 | 指出正文只有功能技巧，没有建站部署过程，核心承诺未兑现 |

人工替换标题仅用于对照测试，没有修改 B 站视频或用户缓存。上述数值是本次实际返回，不能保证其他视频或每次重跑都完全一致。

评分规则版本升级为 3。重新加载扩展后，旧规则下的缓存会在再次使用时重评一次，再继续复用新结果；不会把所有旧的 2 分直接改为 0 分。总分公式和 7 分推荐门槛保持现有规则。
