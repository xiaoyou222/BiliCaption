# 大纲全片总结与字幕获取

## Goal

看视频时，大纲 Tab 一次生成「一段话总览 + 章节时间轴」，和设计稿一致。官方字幕列表在 `player/v2` 为空时用 `dm/view` 再拉一次，空态能分清「真没字幕」和「列表没拉到」，避免把有 AI 字幕的片误判成要转写。

## Background

用户选定方案 A：全片总结是短段落，和大纲同一次生成；同时做字幕 `dm/view` 兜底与失败分类。

当前行为（仓库）：

- 大纲只产出章节 JSON 数组，缓存键 `outline:v2:{bvid}:{cid}` 存数组。`sidepanel.js:2234`、`sidepanel.js:2135`。
- 提示词要求 `from`/`to` 为字幕行号，本地对到秒。`lib/outline.js:120`。
- 字幕只打 `x/player/wbi/v2`，失败再 `player/v2`。`background.js:1276`。空列表就提示没字幕。`background.js:1732`。
- 选区总结、转写通道、WebDAV、标记不在本轮范围。

设计稿（`BiliCaption/BiliCaption Sidebar.dc.html`）：大纲有章节时顶部出现可折叠「全片总结」，默认展开；点「生成大纲」同时流出总结段落和章节。空态仍是「还没有生成大纲」。

参考项目 `参考/AIFeedTracker-main` 可借鉴：`dm/view` 比 player 更能拿到 AI 字幕；失败类型拆开；超长文本才分段合并。不借鉴其「关键观点 + 时间线」长文（和章节重复），也不做自动转写 / 本地 SenseVoice。

## Requirements

1. **一次生成两样东西。** 点「生成大纲」或「重新生成」走同一条总结服务（现有 `runModel`）。成功结果包含：80–150 字中文总览一段话（无标题、无列表、无时间码），以及 3–8 个章节（现有 title / synopsis / 行号 from–to）。
2. **大纲 Tab UI 跟设计稿。** 有章节或已有总结文本时：顶部可折叠「全片总结」（默认展开，chevron 旋转），下面章节时间轴，底部仍是复制 / 下载 Markdown / 重新生成。生成中且还没有任何可见内容时：空态点阵球 +「AI 正在阅读全文字幕…」。停止同时停总结和章节。
3. **流式。** 常见路径一个 JSON：先 `summary` 再 `chapters`，边收边画。总结流式可加光标；章节继续用现有逐段预览。
4. **超长字幕。** 行号字幕文本超过字数预算时，只对全片总结做分段再合并；章节仍用现有行号提示词。两阶段时等第一章出现再切到列表布局；章节失败则整次失败，总结不单独落盘。
5. **缓存。** 同一 `outline:v2:` 键改为 `{ summary, chapters }`。读到旧数组当成 `chapters`，`summary` 为空：章节照常显示，隐藏全片总结块。清理缓存仍删该键。`background.js:1507`。
6. **复制 / Markdown。** 有总结时放在最上面，再跟现有带时间戳的章节。无总结时格式与现在一致。
7. **字幕列表兜底。** `player/wbi/v2`（或 fallback `player/v2`）的字幕轨过滤后为空，才请求 `https://api.bilibili.com/x/v2/dm/view?type=1&oid={cid}&pid={aid}`（`credentials: include`，Referer 为 B 站）。有轨则仍优先 `ai-zh` / 中文自动，再中文，再第一条。`pickDefaultTrack` 规则不变。`background.js:1324`。
8. **空态分类。** 已登录且两个接口字幕列表都为空 → 现有「这个视频没有字幕」+「生成字幕」。已登录但两次拉取都失败 → 标题「没拿到字幕列表」，副文案可重试或直接生成，主按钮仍是生成字幕，提供重试。未登录 / 网络错误保持现有错误页。不自动转写。
9. **本机。** 全片总结只存在本机，和大纲一起。不进 WebDAV。换视频或清缓存即离开。

## Acceptance Criteria

- [ ] 点「生成大纲」后，大纲 Tab 顶部出现可折叠「全片总结」一段话，下面是 3–8 个带时间轴的章节；折叠/展开 chevron 与设计稿一致，默认展开。
- [ ] 流式期间先出现总结或第一章后切到列表布局；点停止后不再追加内容。重新生成覆盖总结和章节。
- [ ] 复制大纲、下载 Markdown 在有总结时以总结段开头；无总结时与现在章节格式相同。
- [ ] 旧缓存数组仍能显示章节，不出现空白总结块；重新生成后写入 `{ summary, chapters }`。清理本视频缓存后两者都消失。
- [ ] `player/v2` 字幕列表为空、`dm/view` 有 `ai-zh` 时，侧栏直接显示官方字幕，不出现「没有字幕」。
- [ ] 已登录、两个接口都返回空列表：空态「这个视频没有字幕」+ 生成字幕。已登录、两个接口都失败：空态「没拿到字幕列表」，可重试，也可生成字幕。未登录/网络页不变。
- [ ] 超长字幕只对总结分段合并，章节时间仍来自行号而不是模型编的秒数。现有 `测试/大纲时间轴.test.js` 继续通过，并补上总结 JSON、旧缓存兼容、字幕兜底与失败分类用例。
- [ ] 选区总结、转写通道、翻译、标记、WebDAV 行为与现在一致。

## Out of Scope

- 不把全片总结做成「关键观点 + 时间线」长 Markdown。
- 不自动转写；不接 SenseVoice / 自建 ASR。
- 不轮询等待新投稿的 AI 字幕。
- 不改选区总结提示词或卡片。
- 不改转写服务商列表（进行中的 `08-20-stt-providers-rewrite` 互不合并）。
- 不把大纲/总结同步到 WebDAV。
- 不给全片总结做双击编辑（设计稿没有）。

## Technical Notes

- 总结服务沿用 `runModel` / 设置页「总结服务」，不新增服务商。
- 章节时间对齐继续走 `BiliCaptionOutline.finalizeOutline`，禁止改成信任模型秒数。
- `dm/view` 只在 player 轨为空时调用，避免每支视频多一次请求。
- 字数预算、JSON 字段顺序、缓存形状见 `design.md`。
